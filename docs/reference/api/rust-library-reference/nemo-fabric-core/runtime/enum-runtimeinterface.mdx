Where to reach one native interface that a runtime serves.

Paths are environment-local. A handle never contains a credential value: `credential_file` names the owner-only file that holds it, when the interface has one.

## Variants

### `Http`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Http"}} /></pre>

HTTP interface listening on a loopback address.

#### Fields

##### `address: IpAddr`

Loopback IP address the interface listens on.

##### `port: u16`

TCP port the interface listens on.

##### `credential_file: Option<PathBuf>`

File holding the interface's credential, when it has one.

### `Terminal`

<pre className="rust-signature"><code dangerouslySetInnerHTML={{"__html": "Terminal"}} /></pre>

Terminal interface that a person opens by running its launcher in the environment, for example with `openshell sandbox exec --tty`.

#### Fields

##### `launcher: PathBuf`

Executable that opens the terminal UI with the runtime's configuration.

##### `credential_file: Option<PathBuf>`

File holding the interface's credential, when it has one.
