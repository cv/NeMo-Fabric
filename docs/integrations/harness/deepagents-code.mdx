Use the `nvidia.fabric.langchain.deepagents-code` adapter to run LangChain's
Deep Agents Code (`dcode`) as an ACP agent. Each NeMo Fabric runtime starts one
`dcode --acp` process and reuses one ACP session across ordered invocations.

## Install the Adapter

Install Node.js 22.19.0 or newer, the adapter, and `dcode` in its own Python
3.14 environment:

```bash
npm install nemo-fabric-adapters-deepagents-code
uv tool install deepagents-code==0.2.2
```

## Configure the Adapter

```python
from nemo_fabric import HarnessConfig

harness = HarnessConfig(
    adapter_id="nvidia.fabric.langchain.deepagents-code",
    settings={"approval_mode": "auto", "interfaces": {"terminal": {}}},
)
```

The model uses provider `openai`, optionally with an OpenAI-compatible
`base_url` and an `api_key_env`. `approval_mode` is required: `auto` uses
`dcode`'s classifier and denies what it escalates, and `yolo` allows every
gated action.

## Open the Terminal UI

With `interfaces.terminal`, the adapter writes a launcher to
`<artifact root>/.fabric/deepagents-code/runtimes/<runtime-id>/interfaces/terminal`,
which the runtime handle reports as `interfaces.terminal.launcher`.
It opens `dcode`'s terminal UI in a separate session that shares the runtime's
configuration and session store, and refuses to start after the runtime stops.
The terminal UI can list the runtime's thread with `threads list`, but can't
open it: the runtime's ACP session holds that thread while the runtime runs.

Apart from what the agent's own tools request, invocations over ACP contact
only the model endpoint. At each start, the
terminal UI's `langgraph dev` agent server sends LangGraph CLI's usage record to
`kzrlppojinpcyyaipxnb.supabase.co`; to opt out, set
`LANGGRAPH_CLI_NO_ANALYTICS=1` in the environment that runs the launcher.
Without `rg` on `PATH`, the terminal UI downloads ripgrep from GitHub, so
install ripgrep in the environment. The adapter turns off reading a workspace
`.env` file, since configuration comes from `FabricConfig`.

For settings, state locations, the launcher's limitations, and health checks,
refer to the
[Deep Agents Code adapter guide](https://github.com/NVIDIA/NeMo-Fabric/tree/main/adapters/typescript/deepagents-code).
